# Regras de Negocio

Regras que nao podem ser quebradas por manutencao sem alinhamento explicito.

Use estes documentos para detalhes transversais, sempre em conjunto com o README
canonico do modulo e o codigo atual. Handoffs e mapas datados nao promovem uma regra
historica a comportamento vigente.

Pontos de maior impacto:

- destino e movimentacao de solicitacoes;
- propriedade financeira de titulos e movimentos;
- compras, cotacoes, fechamento e pedidos;
- contratos legado/novo e medicoes;
- escopo de obra e apropriacoes;
- permissao, anexos e auditoria.
